Features

Everything a Minecraft
player actually needs

🛡️

Armor & Status HUDs

Vertical armor stack with live durability, held item counts, and flying/sneaking/sprinting status — all draggable and resizable.

📍

3D Waypoints

Glowing in-world markers with a rising beam. Name them, color-code them, and they stay scoped to the server you made them on.

⏱️

AFK Sessions

Stay logged into a server in the background — no game window, no rendering. Multiple servers at once, named and saved.

✨

Space Theme

Animated starfield, glowing planets, shooting stars, and a full liquid-glass UI — from the launcher all the way into the game menus.

⌨️

Keybind Presets

Save your full keybind layout as a named preset, color-coded, and switch between setups in one click.

🚀

Performance Mods

Sodium, Lithium, FerriteCore, EntityCulling and more — auto-installed and tuned for your hardware on first launch.

About

What is NebulaClient?

NebulaClient is a custom Minecraft launcher built to give players the tools that Lunar Client and Feather offer, without the bloat. Everything is built in-house — the launcher, the in-game mod, the HUD editor, and the waypoint system.

We build features players actually ask for, ship them fast, and keep the whole thing free. The project is actively developed and updated regularly.

NebulaClient is currently in active development. A public release is coming soon — follow along or reach out below if you want to be notified when it drops.
